
# Bank Management System (C++)

A simple Bank Management System implemented using Data Structures in C++.

## Features

- Create Account
- Display Accounts
- Deposit Money
- Withdraw Money
- Transfer Money
- Search Account
- Sort Accounts by Balance
- Transaction History using Stack
- Customer Waiting Queue using Circular Queue

## Data Structures Used

- Singly Linked List
- Stack
- Circular Queue

## How to Run

Compile:

```bash
g++ BankSystem.cpp -o bank
